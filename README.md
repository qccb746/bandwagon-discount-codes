## 购买流程和几个注意事项

下单本身不复杂：选套餐 → 结算页选择计费周期 → 在 Promotional Code 栏输入优惠码并验证 → 用支付宝或微信付款。几个容易踩的点列在下面：

1. **优惠码必须先验证再付款**。输入后点 Validate，确认总价已经按折扣重新计算。码失效会直接提示，不用猜。
2. **计费周期的单价差很大**。以 KVM 80G 为例，月付 $19.99 一年就是 $239.88，年付只要 $199.99。只要确定长期用，年付几乎总是更划算，双十一的循环码再叠上去，差距进一步拉大。
3. **机房可以后期免费切换**，KVM 和 CN2 GIA-E 系列尤其灵活。选错机房不是不可挽回的事，但切换不影响价格，初始选择还是尽量选对。
4. **新购有退款期**，官方提供 30 天退款保证，不满意可以申请退。限量版套餐和某些特殊促销的退款规则可能不同，下单前看一眼条款页。
5. **高端亚洲机房常年库存紧张**。香港、东京系列经常处于售罄状态，双十一当天放出来的库存会被快速抢完。想买的话提前注册好账号、绑好支付方式，开抢时直接走结算流程。

## 常见问题

**双十一优惠码对老用户续费有效吗？**

以 2025 年的 `ILOVEBANDWAGON` 为例，官方说明是全场循环折扣、终身有效，新购和续费都适用。这也是循环码和"首单折扣"最大的区别。

**错过了双十一还有机会吗？**

有。搬瓦工一年有两个稳定的大促节点：双十一和黑五（11 月底），另外新年、周年庆偶尔也会放码。此外社区长期流通的小力度码（5%–6%）在非活动期偶尔可用，可以到结算页试。

**为什么搬瓦工的折扣力度普遍只有 5%–11%，比其他主机商小很多？**

这是它的定价策略决定的。搬瓦工不搞虚高原价再打折那一套，$49.99/年 的 KVM 和 $169.99/年 的 CN2 GIA-E 常年就是标签价，优惠码是在已经很低的实际成交价上再让一点。CN2 GIA 这类直连线路本身的带宽成本远高于普通线路，能给出 11% 已经是让出相当一部分利润了。

**香港和东京套餐价格一样，选哪个？**

两地都是三网直连 CN2 GIA，标价完全相同（$89.99/月 起）。一般来说大陆用户到香港的延迟略低于东京，但具体到你自己家宽的实测结果才有意义。两个机房都支持切换测试，选到手的那个再决定要不要留。

**现在（活动空窗期）该不该直接原价买？**

看你用途的紧迫程度。如果是长期能用上的需求，早买一个月就多用一个月，年付套餐摊下来每天不到五毛美元，等一两个月的优惠省的钱可能还没覆盖这段时间的使用价值。如果只是囤着以后用，等 11 月的双十一码更合理。
